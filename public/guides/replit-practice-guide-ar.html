١ ما هو Replit؟

التعريف

Replit هو منصة تطوير بمساعدة الذكاء الاصطناعي تتيح للمستخدمين إنشاء وتحرير وتشغيل واختبار التطبيقات في المتصفح. يجمع بين مساحة عمل البرمجة ودعم الذكاء الاصطناعي ومعاينة التطبيق والنماذج الأولية السريعة — كل ذلك من متصفحك بدون تثبيت.

الميزات الرئيسية

  • تطوير سحابي - لا حاجة لتثبيت أي شيء
  • توليد كود بالذكاء الاصطناعي - صف ما تريده والذكاء الاصطناعي يكتب الكود
  • معاينة فورية - شاهد تطبيقك يعمل في الوقت الفعلي
  • دعم لغات متعددة - يعمل مع Python و JavaScript و HTML وغيرها
  • تطوير تعاوني - شارك مساحة العمل وابنِ مع الآخرين
  • مساعد AI للدردشة - اسأل الذكاء الاصطناعي لشرح الكود أو إصلاح الأخطاء

ما الفرق بين Lovable و Replit؟ بينما Lovable يعتمد بالكامل على الأوامر النصية (لا ترى الكود أبداً)، Replit يعطيك مساعد AI وأيضاً وصولاً للكود الأساسي. هذا يعني أنه يمكنك ترك الذكاء الاصطناعي يقوم بالعمل الثقيل مع إمكانية تعديل الكود يدوياً إذا لزم الأمر.

  • كيفية إنشاء حساب والتنقل في مساحة عمل Replit

  • كيفية تحسين التطبيق خطوة بخطوة
  • كيفية إضافة تصنيف الإلحاح وتصدير التقارير
  • الفرق بين Replit وأدوات البرمجة الوصفية الأخرى

٥ سيناريو العرض: حالة استخدام صحية

السيناريو

سننشئ مولّد تقارير سريرية لطبيب. سيقوم التطبيق بـ:

  • قبول أعراض المريض والبيانات السريرية كمدخلات
  • توليد ملخص سريري منظم
  • تصنيف مستوى الإلحاح (منخفض، متوسط، عالي)
  • تصدير التقرير بتنسيق منظم للتوثيق

٦ الأمر ١: إنشاء تطبيق الملخص السريري

توليد التطبيق الأولي

الهدف: بناء نموذج يجمع بيانات المريض ويولّد ملخصاً سريرياً

Create a simple web app for doctors where they can enter patient symptoms and generate a clinical summary. The app should include input fields for patient name, age, symptoms, and notes. It should have a clean interface and display the generated summary clearly.

انسخ هذا الأمر والصقه في مساعد AI في Replit

ما المتوقع
  • تطبيق ويب كامل مع واجهة نموذج
  • حقول إدخال لاسم المريض والعمر والأعراض والملاحظات
  • زر "توليد الملخص"
  • الملخص السريري معروض بوضوح أسفل النموذج

٧ الأمر ٢: إضافة تصنيف الإلحاح

تعزيز بمستويات الإلحاح

الهدف: إضافة تصنيف إلحاح تلقائي

Enhance the app by adding an urgency classification section. Based on the entered symptoms, show a simple urgency level such as Low, Medium, or High. Display the urgency clearly below the clinical summary.

الصق هذا كأمر متابعة في نفس المشروع

ما المتوقع
  • شارة إلحاح ملونة (أخضر=منخفض، أصفر=متوسط، أحمر=عالي)
  • تصنيف بناءً على كلمات الأعراض المدخلة
  • تمييز بصري يجعل الإلحاح واضحاً فوراً

٨ الأمر ٣: مخرجات منظمة وتنزيل

إضافة مخرجات منظمة وتصدير

الهدف: تنسيق التقرير مهنياً وإضافة وظيفة التنزيل/الطباعة

Improve the app by formatting the output into clear sections: patient details, symptoms, clinical summary, and urgency level. Also add a button that allows the doctor to download or print the result for documentation purposes.

الصق هذا كأمر متابعة في نفس المشروع

ما بنيته

باستخدام ثلاثة أوامر فقط، أنشأت مولّد تقارير سريرية يتضمن:

  • نموذج جمع بيانات المريض
  • توليد ملخص سريري تلقائي
  • تصنيف إلحاح بالذكاء الاصطناعي
  • مخرجات تقرير منظمة ومهنية
  • إمكانية التنزيل/الطباعة للتوثيق الطبي

٩ تمارين عملية

التمرين أ: تحسين مولّد التقارير

استمر في البناء. جرب كل أمر على حدة:

إضافة العلامات الحيوية:

Add input fields for vital signs: temperature (in Celsius), heart rate (BPM), blood pressure (systolic/diastolic), and oxygen saturation (%). Include these in the generated report and use them to improve the urgency classification accuracy.

إضافة توصيات المتابعة:

Add a section in the report that suggests follow-up actions based on the urgency level. For Low urgency, suggest scheduling a routine follow-up. For Medium, suggest further tests within 48 hours. For High, recommend immediate specialist referral with specific warnings.

إضافة سجل التقارير:

Add a history panel on the side that shows previously generated reports. Each entry should show patient name, date, and urgency level. Clicking an entry should display the full report. Add a search bar to find previous reports by patient name.

التمرين ب: بناء أداة صحية جديدة

ابدأ مشروعاً جديداً في Replit:

الخيار ١ - مفسّر نتائج المختبر:

Create a web app where doctors can enter lab test results including blood count (hemoglobin, WBC, platelets), glucose level, cholesterol (total, HDL, LDL), and creatinine. For each value, show whether it is Normal, Low, or High compared to standard medical reference ranges. Display the results in a clear table with color coding: green for normal, yellow for borderline, and red for abnormal values.

الخيار ٢ - أداة تسليم المناوبة:

Create an app for nurses to document patient status during shift handover. Include fields for patient name, room number, current condition, vital signs summary, medications given during the shift, pending tasks for the next shift, and special notes or alerts. Generate a structured handover report that the next shift nurse can review quickly. Include a print button.

الخيار ٣ - فاحص الأعراض:

Create a simple symptom checker where patients can enter their symptoms from a list of common symptoms using checkboxes. Based on the selected symptoms, display a general recommendation: "Self-care at home", "Schedule a doctor appointment within a few days", or "Seek emergency medical care". Add a disclaimer that this is not a medical diagnosis. Include a button to generate a printable summary to bring to the doctor.

١١ نصائح لنتائج أفضل مع Replit

ابدأ بقصة المستخدم: ابدأ أمرك بـ "As a doctor, I want to..." لمساعدة الذكاء الاصطناعي على فهم السياق.

حدد تنسيق المخرجات: صف كيف يجب عرض البيانات: "show results in a table"، "display as cards".

أضف ميزة واحدة في كل مرة: لا تحاول وصف تطبيق معقد في أمر واحد. ابنِ تدريجياً.

اختبر بعد كل تغيير: استخدم معاينة Replit المباشرة للتحقق من عمل التطبيق.

استخدم دردشة AI للمساعدة: إذا لم يعمل شيء، اسأل المساعد لإصلاح المشكلة.

تذكير مهم: التطبيقات المبنية في هذا التمرين هي لأغراض التعلم فقط. ليست برمجيات طبية معتمدة ولا ينبغي استخدامها لاتخاذ قرارات سريرية فعلية.
